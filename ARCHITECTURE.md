## 数据流

### 1. 用户登录流程

```
用户 → Vue登录页 → POST /api/auth/login
                          ↓
                    Spring Security
                          ↓
                    验证用户名/密码
                          ↓
                    生成JWT Token
                          ↓
                    返回Token给前端
                          ↓
                    前端存储Token (localStorage)
```

### 2. 数据查询流程

```
用户 → Vue页面 → GET /api/servers
                    ↓
              JWT验证 (拦截器)
                    ↓
              Controller处理
                    ↓
              Service业务逻辑
                    ↓
              Repository查询
                    ↓
              PostgreSQL数据库
                    ↓
              返回JSON数据
                    ↓
              Vue渲染页面
```

## 部署架构

### 开发环境

```
本地开发机
├── Maven (构建Java后端)
├── npm (构建Vue前端)
├── PostgreSQL (本地数据库)
└── IDE (开发工具)
```

### Docker环境

```
Docker Host
├── itop-web容器
│   └── Nginx + Vue静态文件
├── itop-api容器
│   └── Spring Boot应用
└── postgres容器
    └── PostgreSQL数据库

Docker Network: itop-network
Docker Volumes: postgres_data
```

### 生产环境（推荐）

```
负载均衡器
├── itop-web (多实例)
│   └── Nginx
├── itop-api (多实例)
│   └── Spring Boot
└── PostgreSQL (主从复制)
    ├── Master (写)
    └── Slave (读)
```

- ✅ 分层架构（关注点分离）

- ✅ 依赖注入（Spring IOC）
- ✅ RESTful API设计
- ✅ 前后端分离
- ✅ 容器化部署
